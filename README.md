# 🎴 بازی بلف (Bluff) - بات تلگرام

بازی کارتی بلف (دروغ‌گو) به‌صورت Mini App داخل تلگرام، با پشتیبانی از بازی چندنفره از طریق لینک دعوت.

## امکانات

- 🤖 **تمرین با بات:** ۱ تا ۵ بات و ۱ تا ۹ دست، بدون سکه
- 👥 **بازی با دوستان:** ۲ تا ۶ نفر، انتخاب تعداد دست، لینک دعوت و ورود با کد
- 🃏 **میز بازی:** هر بازیکن یک سمت میز، پخش کارت از وسط میز، کارت‌های روی میز مخفی
- 🚨 **بلف:** انتخاب ۱ تا ۴ کارت و ادعای عدد آن‌ها، حریف می‌تواند بلف بزند یا رد کند
- 🏆 **جایزه:** برنده‌ی بازی دوستانه (حداقل ۲ بازیکن واقعی) ۵۰۰ سکه می‌گیرد، همراه با جدول برترین‌ها
- 👤 **پروفایل:** نام کاربری یکتا و آواتار

## قوانین

1. هر نوبت ۱ تا ۴ کارت پشت‌رو روی میز بینداز و بگو چه عددی هستند (راست یا دروغ).
2. بعد از اولین کارت، همه باید همان عدد را ادعا کنند تا وقتی کسی بلف بزند.
3. هر حریف می‌تواند «بلف» بزند:
   - اگر ادعا دروغ بود، همه‌ی کارت‌های وسط میز به بلف‌زننده‌ی اصلی (دروغ‌گو) برمی‌گردد.
   - اگر ادعا راست بود، همه‌ی کارت‌ها به کسی می‌رسد که بلف گرفته.
4. اولین نفری که کارت‌هایش تمام شود (و کسی بلف درستی نزند) دست را می‌برد.
5. برنده‌ی نهایی کسی است که بیشترین دست را برده باشد.

## نصب و اجرا

نیازمندی: Node.js نسخه 18 یا بالاتر

```bash
npm install
BOT_TOKEN=توکن_بات BOT_USERNAME=یوزرنیم_بات WEBAPP_URL=https://your-domain.com npm start
```

برای تست محلی بدون تلگرام می‌توانید `DEV=1` اضافه کنید.

### متغیرهای محیطی

| نام | توضیح |
|---|---|
| `BOT_TOKEN` | توکن بات از BotFather |
| `BOT_USERNAME` | یوزرنیم بات بدون `@` |
| `WEBAPP_URL` | آدرس HTTPS سرور (بدون `/` آخر) |
| `PORT` | پورت سرور (پیش‌فرض ۳۰۰۰) |
| `DEV` | اگر `1` باشد ورود آزمایشی بدون تلگرام فعال می‌شود |

> ⚠️ توکن بات را هرگز در کد یا ریپو قرار ندهید.

## راه‌اندازی بات

1. در تلگرام به `@BotFather` برو و با `/newbot` بات بساز.
2. پروژه را روی یک سرور با HTTPS اجرا کن (تلگرام فقط HTTPS را برای Mini App می‌پذیرد).
3. به بات `/start` بزن و دکمه‌ی «ورود به بازی» را انتخاب کن.

لینک دعوت به شکل `https://t.me/یوزرنیم_بات?start=کد_اتاق` است.

## ساختار پروژه

```
server.js          # بات تلگرام، سرور WebSocket، منطق بازی و سکه‌ها
public/index.html  # رابط کاربری Mini App
package.json
```

## محدودیت‌ها

- اطلاعات کاربران و سکه‌ها در فایل `db.json` ذخیره می‌شود و روی سرویس‌هایی که دیسک موقت دارند با ری‌استارت پاک می‌شود.
- تایمر نوبت ندارد.
- بازی‌های در جریان با ری‌استارت سرور از بین می‌روند.
